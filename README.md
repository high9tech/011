# HIGH TECH PS Host (Offline-Ready)

مضيف ويب مخصص وأنيق لجهاز البلايستيشن، يعمل بزر موحد مركزياً لدعم التنفيذ المباشر مع دعم التخزين المؤقت للعمل بدون الحاجة إلى الاتصال بالإنترنت (**Offline Mode**).

---

## 🚀 المميزات (Features)

* **تصميم عصري وحديث:** واجهة تفاعلية بسيطة وشاشة تنبيهية مضيئة.
* **زر موحد (Central Action Button):** تم الغاء الخيارات المتعددة ودمج الواجهة في زر رئيسي موحد يحمل اسم **HIGH TECH PS / jailbreak**.
* **سجل أحداث موحد (Console Box):** يعرض مخرجات العملية ومراحل التحميل خطوة بخطوة.
* **دعم العمل بدون إنترنت (Offline Caching):** يشتمل على `sw.js` (Service Worker) لتخزين جميع الملفات في كاش المتصفح تلقائياً عند الزيارة الأولى.
* **متوافق مع GitHub Pages:** جاهز للنشر المباشر على خوادم GitHub مجاناً.
